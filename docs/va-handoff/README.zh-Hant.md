## 「id」是什麼意思（到處都會看到）
**id** 是品牌的英文簡稱：只用小寫英文字母／數字，空格改成連字號 `-`，不要中文、不要符號。
- 真芳 碳烤吐司 → `zhenfang`　·　Chill Ice Bath → `chill-ice-bath`
- 既有品牌都已經有 `id` — **絕對不要更改。**
- 新品牌取一個新的 id（用上面的方式），這個 id 同時也是它的 logo 檔名。

## 任務 A — 品牌 Logo ⭐ 從這裡開始
為每個品牌收集一張全新 logo，放進 logo 資料夾。
- **檔名 = 品牌的 `id` + `.png`** — 例如 `zhenfang.png`、`vacanza.png`。（`id` 是 `brands` 分頁的第一欄。）
- **所有 PNG 直接放在同一個資料夾** — 不要建子資料夾。
- **必須是透明背景。** logo 要放在透明底上（預覽 PNG 時會看到灰白格子），**不要**包在白色或彩色方塊裡。如果只找得到有底色的版本，請標記該品牌、先不要上傳有底色的。
- **大且清晰** — 最長邊至少 **800 px**（越大越好）。向量圖（SVG）轉 PNG 最理想。不要用截圖、模糊或鋸齒的圖。
- **只用官方來源：** 品牌官網頁尾／新聞或品牌資源頁／官方社群帳號。
- **每個品牌都要做**（全部 20 個）— 再加上 Johnson 新增的品牌。
- ✅ 資料夾裡有一張透明、高解析的 `{id}.png` = 該品牌完成。（不用管 `has_logo` 欄，那是自動的。）

## 任務 C — `locations` 分頁 ⭐ 主要工作
地圖會為每一家實體門市顯示一個圖釘。目前只有起始的少量資料 — **大部分品牌都還缺分店。** 為**每個實體品牌**，把**每一家**門市加成一列：
1. 找品牌官方的 **門市 / 據點 / 門市查詢** 頁面（最可靠，比 Google 地圖好）。
2. 一家門市一列：**門市名稱（中／英）+ 完整、精確的地址。**
3. **`lat` / `lng` 從 Google 地圖填** — 在 Google 地圖找到該門市，**在圖釘上按右鍵 → 點那串 `25.0…, 121.5…` 數字即可複製**，貼到 `lat`、`lng` 兩欄。地址本身也**必須精確**（門牌號、行政區、樓層）。
4. **`brand_id` 必須與 `brands` 分頁的 `id` 完全一致**（小寫）。
5. **`kind` 欄：** 客人可以走進去逛的店面 → **留空**。只有客人不會去的公司辦公室／總部才填 `hq`（小寫）— 這些仍會顯示在品牌頁，只是不會出現在地圖圖釘。（若某地點既是旗艦店又是辦公室，當作店面：留空。不確定就留空。）
6. **純線上、沒有實體據點的品牌？** 不用新增任何門市列 — 只要確認它在 `brands` 分頁的 `type` 是 `online`，它就會自動出現在線上品牌目錄。
7. `gmaps_url` 留空 — 不需要。

> 例：Vacanza 有 30 家以上分店，但表裡只有幾家 — 請把其餘的補上。
